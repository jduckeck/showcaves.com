AI-generated Content On showcaves.com


It is a sign of the times that more and more texts are being written by AI. These are, to a greater or lesser extent, convenient search engines that provide ready-to-print summaries of search results. This is very convenient and is therefore very popular as a way of saving time and easily generating entire websites. Unfortunately, it doesn’t work. The problem is often attributed to the technical term hallucination. This is a technical term which simply means the AI is spouting nonsense. For this reason, we have already created a page featuring the worst AI-based websites that invent information about caves. The problem is that AI systems on the internet are already being trained using the hallucinated content from such websites. The result is even more absurd texts. And to top it all, these generated websites make life so difficult for creators of genuine content that many are giving up, particularly in the field of journalism. This means that the proportion of well-researched content becomes even smaller.


In our view, producing text content using AI is a no-go. Furthermore, AI-generated content must increasingly be labelled as such. We have therefore decided to lay down the basic rules for showcaves.com:

  1. All texts on showcaves.com have been created by humans.
  2. Search engines and, to a limited extent, AI are used for research, but only to find original sources.
  3. The content of the texts is based on original sources written by humans, which have been thoroughly checked for credibility.
  4. The images have either been provided for publication or are in the public domain, which nowadays, of course, means that they may have been generated by AI. Where we have noticed this, the images were labelled accordingly.
  5. We have created images using AI for logos or symbolic images. We believe this is helpful. With logos, it is generally not possible to label them as AI-generated.
  6. Realistic depictions are, of course, labelled as AI-generated.
  7. AI is used extensively in translation these days, and we utilise such software for our bilingual pages. Nevertheless, the results are thoroughly proofread, which is particularly essential given the large number of technical terms.
  8. There are no real pictures for certain topics, for example extinct animals, so we sometime use AI generated images for such topics, if they have sufficient quality.
  9. All AI generated pictures on the website have the path /ai/.
  10. An early experiment, the fictional country of Molvania – intended as a joke – contains images which are neither marked as AI-generated nor located in the directory mentioned above. This is because it was created before we had these rules in place. Besides, it would spoil the fun.
