Submit Information


Do you miss a beloved show cave, show mine or any other underground site? Is information about the sight incomplete, wrong, missing, or do you know better? Do you know about some geology, historic undergrounds, gorges, caving techniques helpful for beginners, or just about terminology in other languages? Do you have a public domain (CC-0) picture you can provide? Do you have an ebook about the topic we may add to the download section?

Tell us as much or as little as you want, anything helps. We are really fond of any information, and we will do our best to add it ASAP. If you send facts we will write or extend the existing description. If you send any content, text, pictures, whatever, we need you to release it into public domain. Of course, we will add the author, but we do not accept any copyrighted material, because this requires far too much work. We have to validate the requested licence, and there are dozens, and we have to make a database for the different requirements. The danger of legal issues is too big as well.

If you want to discuss or help with the website, we are using Slack and GitHub for the management of the website. So if you want an offline version, just go to GitHub and download the full website. Open the index.html file from disk and enjoy! If you want to collaborate we will be happy to send you an invitation to the Slack workspace, so we can discuss anything related. If you feel fit to edit HTML we can talk about write access to the GitHub. This is quite dangerous so we will do it only if you are really interested and after some time in Slack.


As a result there are some basic rules you should check before you send anything:

  • First the most important rule: There is so much spam on the web, we must make sure the info you provide is not a fake or hoax. Help us to find out if you are reliable. A smartphone photo of the price list and open hours is better and faster than writing it down, and is reliable. A reference to an "official" website with similar content helps also.
  • Is the text/picture free of copyright (CC-0)?
  • Is there a page where you want it published or do you think it’s a new page?
  • If it’s a text of some size or an image we are willing to mention the author, despite the CC-0 status.
  • Provided links are added under the Link Policy.
  • We do not publish Artificial Intelligence.

Owners of show caves or show mines are welcome! Tell us if you are not listed and we will list you. Listing your cave or update the existing information is free. But keep one thing in mind: this is not free webspace for your enterprise! We will decide which information and how we will publish it. We will not advertise your company, will not add text links to push your search engine ranking or add your banners. In general, we try to provide compact, exact and useful information. If your location is not a rip-off, you might be surprised how much an independent review can help you.
